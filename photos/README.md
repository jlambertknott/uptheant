Put trip photos in this folder.

Any .jpg, .jpeg, .png or .webp dropped in here turns up on the
"Across the Years" tab about a minute after it's uploaded. They're
resized automatically, so there's no need to shrink them first.

Name a file like `01-jimmy-at-the-helm.jpg` if you want to control the
order. Captions are added in the app, not here.
